# 🚗 AI Contract Analyzer (Car Lease Review & Negotiation Assistant)

An AI-powered system that analyzes car lease contracts, identifies risky clauses, and provides intelligent suggestions for better negotiation.

---

## 🚀 Features

- 📄 Upload lease contracts (PDF/Text)
- 🧠 AI-based contract analysis
- ⚠️ Detect risky or unfair clauses
- 💡 Suggest negotiation improvements
- 📊 Dashboard with insights and reports

---

## 🏗️ Tech Stack

### 🔹 Frontend
- React (Vite)
- JavaScript
- CSS

### 🔹 Backend
- Python (FastAPI / Flask)
- REST APIs

### 🔹 AI / ML
- LLM-based contract analysis
- NLP techniques for clause detection
