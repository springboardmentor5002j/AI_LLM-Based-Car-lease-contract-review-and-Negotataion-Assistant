# 🎓 EduVision – Global Higher Education Analytics

🌍 An interactive Tableau dashboard exploring global university performance and rankings.

📊 Analyzes research productivity, student diversity, and faculty-to-student ratios.

🐍 Uses Python and Pandas for data cleaning and preparation.

📈 Combines QS and THE university ranking datasets to uncover meaningful insights.

🎯 Features interactive visualizations, KPI cards, filters, and dashboard navigation.

🛠️ Tools: Python, Pandas, Google Colab, Tableau.

💡 **Goal:** Transform complex university data into clear, data-driven insights.

🚀 Developed as part of the Infosys Springboard virtual internship project.
